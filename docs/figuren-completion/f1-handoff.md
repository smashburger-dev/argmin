# F1 handoff

F1 exposes verified CPython trace snapshots as local deterministic trace-tag tasks. The task receives the positive source, one selected executed event, the immediately preceding bindings, and the accumulated object glossary from earlier events. The solver answer stays separate from the task and scene model. Object marks follow first observation within a single trace; this describes the recorded CPython identity relation, not a general small-integer interning rule.

The procedural family is `trace-tag-after-line`; `createTraceTagTask` builds the task and reference answer from one of seven versioned CPython records. Its authored cases are metadata only; every one of the seven cases is instantiated across seeds from actual frozen recorder events, and compilation rejects missing or empty binding answers. Case-authored event-kind allowlists bound seeded target selection to executed events. `solve` rebuilds the answer for the same record and target ordinal, and rejects targets outside the case allowlist. The trace prefix hint contract in `trace-hint-prefix.schema.json` exposes only the authored source prefix and prior step captions before the target. The selected event ordinal, event type, frame, source line, prior bindings, and prior object glossary let learners distinguish repeated executions without revealing target or future state.

The compiler reads authored answer values through the optional family `hintAnswers(parameters)` hook, falling back to `solve(parameters)` for numeric families. It preserves strict numeric-answer validation for those families. The fixed training-curve neighbor is the sole nonnumeric classification path: it must use one identical projection across all three cases, profiles, and seeds and visibly present Underfitting, Stabil, and Overfitting symmetrically.

Trace-stage selectors use primitive keys from `trace-board`: binding targets select `name-box-*`, objects select `object-box-*`, returns select the returned object box with the generic object target omitted, and output selects `output-box`. The scene uses expanded target rectangles; rendered pixel size still requires measured viewport verification.
